Tool logos shown in the Skills toolkit strip. File names must match the
"logo" paths under toolkit in content.js:

  google-ads.png   ga4.png   gtm.png   search-console.png   meta.png
  salesforce.png   wordpress.png   claude.png   chatgpt.png

To replace one, upload a new file with the same name (a square PNG with a
transparent or white background works best). If a file is missing, a
coloured monogram shows instead.
